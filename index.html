Windows Desktop App Batch Crop History + OCR

사진을 빠르게 자르고, 여러 장에 반복 적용하는 Windows 작업 공간

Grid Crop Studio는 Windows에서 사진 자르기, 여러 장 일괄 자르기, JSON 레이아웃 저장과 불러오기, 작업 기록 보기, 선택형 OCR 흐름까지 지원하는 데스크톱 이미지 작업 도구입니다. 반복되는 스크린샷 자르기, 카드형 이미지 분할, 블로그용 자산 제작, 같은 규칙의 대량 저장 작업을 더 빠르게 처리할 수 있습니다.

Why This Tool

반복 작업을 위한 실제 데스크톱 작업 도구

무거운 편집기 대신 바로 열리고 바로 자르고 바로 저장할 수 있는 작업 흐름에 초점을 맞췄습니다.

Fast Photo Cutting

사진을 열고 영역을 정한 뒤 저장하는 흐름을 짧게 유지했습니다.

Reusable Layouts

한 번 만든 자르기 영역을 JSON으로 저장하고 같은 형식의 이미지에 반복 적용할 수 있습니다.

Windows Distribution

PyInstaller 기반 EXE 빌드를 제공해 Python 환경이 없는 PC에서도 배포하기 쉽습니다.

Core Features

핵심 기능

자주 쓰는 흐름만 남기고, 반복 작업에 필요한 기능을 중심으로 구성했습니다.

Clipboard Paste

`Ctrl + V`로 사진을 바로 붙여넣어 빠르게 작업을 시작할 수 있습니다.

Multi-Region Cutting

여러 개의 자르기 영역을 만들고 이동, 삭제, 조절할 수 있습니다.

JSON Save and Load

반복 작업을 위해 좌표와 출력 설정을 저장하고 다시 불러올 수 있습니다.

Batch Processing

한 번 만든 규칙을 여러 장 사진에 그대로 적용해 한 번에 저장할 수 있습니다.

History Viewer

저장 작업과 OCR 작업을 기록으로 남기고 다시 확인할 수 있습니다.

Optional OCR

원하면 C++ OCR 실행기와 모델 ZIP을 연결해 글자 읽기 흐름까지 확장할 수 있습니다.

Workflow

작업 흐름

처음 사진 로드부터 저장까지의 단계를 짧고 분명하게 유지했습니다.

Recommended Flow

사진을 열거나 붙여넣고, 저장 폴더를 정하고, 자를 영역을 만든 뒤, 확정하고 저장하면 됩니다. 같은 작업을 반복할 경우 JSON 레이아웃을 다시 불러와 시간을 줄일 수 있습니다.

  1. 01
    사진 열기 또는 Ctrl + V 붙여넣기
  2. 02
    저장 폴더 정하기
  3. 03
    영역 만들고 위치 조절하기
  4. 04
    확정 후 잘라서 저장하기

FAQ

자주 묻는 질문

공개 페이지에서 바로 이해할 수 있도록 핵심 질문만 간단히 정리했습니다.

어떤 작업에 잘 맞나요?

스크린샷 자르기, 카드형 이미지 분할, 블로그 자산 제작, 반복되는 다중 자르기 작업에 적합합니다.

클립보드 이미지도 바로 붙여넣을 수 있나요?

가능합니다. `Ctrl + V`로 사진을 바로 가져와 작업을 시작할 수 있습니다.

레이아웃을 다시 사용할 수 있나요?

가능합니다. JSON으로 저장한 자르기 레이아웃을 다시 불러와 재사용할 수 있습니다.

여러 장도 한 번에 저장할 수 있나요?

가능합니다. `여러 장` 기능으로 같은 자르기 규칙을 여러 이미지에 반복 적용할 수 있습니다.
